# 🚜 Agri-Equip Management System
### ระบบจัดการรถเกษตรและงานซ่อมบำรุงครบวงจร (ALL IN ONE)

**Agri-Equip Management System** คือ Web Application สำหรับบริหารจัดการธุรกิจรับจ้างรถเกษตร  
เช่น รถไถ รถเกี่ยวข้าว และเครื่องจักรกลการเกษตรอื่น ๆ  
ระบบถูกออกแบบมาเพื่อช่วยลดความซับซ้อนในการจัดการคิวงาน  
ควบคุมต้นทุนน้ำมัน ติดตามการทำงานของพนักงาน  
และจัดเก็บประวัติการซ่อมบำรุงอย่างเป็นระบบ

แพลตฟอร์มนี้เชื่อมการทำงานของ **ลูกค้า ผู้ดูแลระบบ และพนักงานขับรถ**  
ไว้ในระบบเดียว เพื่อเพิ่มประสิทธิภาพ ลดความผิดพลาด และเพิ่มความโปร่งใสในการดำเนินงาน

---

## 🧩 ภาพรวมระบบ (System Overview)

ระบบแบ่งการใช้งานตามบทบาทผู้ใช้ 3 กลุ่มหลัก ได้แก่

**ลูกค้า (Customer)**  
สามารถจองคิวงาน เลือกวันเวลาและประเภทรถ แจ้งชำระเงิน  
ติดตามสถานะงานแบบ Real-time และดูประวัติการใช้บริการย้อนหลังได้ด้วยตนเอง

**ผู้ดูแลระบบ (Admin)**  
ทำหน้าที่เป็นศูนย์กลางควบคุมระบบ ตรวจสอบและอนุมัติงาน  
บริหารจัดการเครื่องจักร พนักงาน และสต็อกน้ำมัน  
พร้อมดูรายงานต้นทุน รายรับ–รายจ่าย และกำไร–ขาดทุนของแต่ละงาน

**พนักงาน (Staff)**  
ใช้งานผ่านมือถือเป็นหลัก ดูงานที่ได้รับมอบหมาย  
บันทึกเวลาเริ่ม–จบงาน ถ่ายรูปหน้างาน  
ขอเบิกน้ำมัน และแจ้งซ่อมเครื่องจักรเมื่อพบปัญหา

---

## ⚙️ ความสามารถหลักของระบบ (Core Functionalities)

- ระบบจองงานรถเกษตร (Booking System)
- ติดตามสถานะงานแบบ Real-time
- ระบบแจ้งชำระเงินและอัปโหลดสลิปโอนเงิน
- รองรับการตรวจสอบสลิปอัตโนมัติผ่าน API
- บริหารจัดการสต็อกน้ำมันและการเบิกใช้งาน
- คำนวณต้นทุนต่อพื้นที่งาน (Profit / Loss)
- บันทึกประวัติการซ่อมบำรุงและอายุการใช้งานเครื่องจักร
- แจ้งเตือนงานใหม่ผ่าน LINE Notify
- ออกใบเสร็จและ Export รายงานเป็น Excel
- รองรับการใช้งานบนมือถือ (Responsive Design)

## 🛠️ เทคโนโลยีที่ใช้ (Technology Stack)

- **Backend:** Laravel 11 (PHP >= 8.2)
- **Frontend:** Blade Templates, Tailwind CSS
- **Database:** MySQL
- **Integration:** LINE Notify API, SlipOK API (Optional)
- **Tools:** Composer, Node.js, NPM
